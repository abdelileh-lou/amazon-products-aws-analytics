# Testing

## Overview

Testing was performed to verify that the S3 data could be accessed by QuickSight and used successfully for analytics.

## S3 Test

The following was verified:

* The S3 bucket exists.
* The CSV file was uploaded successfully.
* The CSV file can be identified in the S3 bucket.

## QuickSight Data Source Test

The QuickSight S3 data source was tested to verify that QuickSight could access the CSV data.

## Dataset Test

The QuickSight dataset was checked to verify that:

* The dataset was created successfully.
* The expected fields were detected.
* The data could be used in an analysis.

## Analysis Test

The QuickSight analysis was tested by creating visualizations from the dataset.

## Dashboard Test

The final dashboard was checked to verify that:

* Visualizations load correctly.
* Data is displayed correctly.
* Filters and interactions work as expected.

## Result

The S3-to-QuickSight analytics workflow was successfully tested.
